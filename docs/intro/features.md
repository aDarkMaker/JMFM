# 功能特性

## 网络与取数

- **API 通道**：不依赖 HTML 入口，规避域名封锁。
- **动态域名**：启动时解密最新域名列表。
- **域名轮换**：请求失败切换备选；超时与重试次数可配。

## 图片重组

- **条带计算**：按专辑特征与图片序号算切分数（getNum）。
- **条带重排**：按源图位置裁剪、逆序拼接。
- **格式**：webp 走重组；gif 原样保留；jpg 按需处理。

## 本地存储与阅读

- **pages 主产物**：下载只写 `albumDir/pages/`（默认 webp）。
- **图片阅读器**：直接渲染本地 pages/。
- **可选 PDF**：运行时提供 `createAlbumPdf`（统一宽度、零白边），不阻塞下载主路径。
- **资源修复**：设置页检查元数据、格式+页数、封面，不合格项删目录并重入队列。

## 配置

关键参数在 `src/config/app-config.json`：

- 域名列表（HTML / API / CDN / 域名服务器）
- 应用密钥与版本号
- 请求头、超时、重试
- 下载并发上限
- PDF 页面尺寸与最大宽度

## 工程结构

- **前后端分离**：`src/core` 不依赖 UI，可单测。
- **多运行时**：Capacitor / Web / Node 共用同一套接口。
- **单测**：getNum、条带重组等核心算法有覆盖。
