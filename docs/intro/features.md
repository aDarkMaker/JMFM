# 功能特性

## 稳定数据获取

- **API 通道优先**：不再依赖 HTML 网页，避免 DNS 封锁导致整条链路失败。
- **动态域名刷新**：启动时从域名服务器拉取 AES 加密的最新域名列表并解密，域名过期可自动更新。
- **多域名轮换**：请求失败自动切换下一域名，超时 / 重试次数可配置。

## 图片解密与重组

- **条带计算**：`getNum` 根据专辑 scrambleId、专辑 ID、文件名计算条带数量（0 / 10 / 8 三种档位）。
- **条带重排**：按计算出的条带高度与源图位置裁剪，逆序拼回完整图片。
- **格式适配**：webp 走重组流程，gif 原样保留，jpg 按需处理。

## 高质量 PDF

- **统一宽度**：所有页面等比例缩放到统一宽度，动态取 `min(全部源图最大宽度, 1190)`，只缩小不放大。
- **无白边**：页面尺寸即图片尺寸，`imageFit: 'fill'`，不补白色背景。
- **标题命名**：PDF 以漫画标题命名（去非法字符、截断 200 字），而非数字 ID。

## 可配置

所有可配置项集中在 `src/config/app-config.json`，包括：

- 域名列表（HTML / API / CDN / 域名服务器）
- 应用密钥与版本号
- 请求头（User-Agent、Referer、Accept）
- 超时与重试参数
- 下载并发上限
- PDF 页面尺寸与最大宽度

## 工程化

- **前后端分离**：`src/core` 纯业务，不依赖 UI；UI 层后续独立设计。
- **双运行时**：RN 运行时（Skia + images-to-pdf）与 Node 运行时（ImageMagick）共用同一套 `DownloadRuntime` 接口。
- **可测试**：核心算法均有 Jest 单测；`scripts/verify-download.ts` 可在 Node 环境跑通完整链路。
