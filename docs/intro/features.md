# 功能特性

## 稳定获取，不挑网络

- **API 通道优先**：摆脱对网页入口的依赖，从根源上避开域名封锁。
- **动态域名刷新**：启动时自动解密最新域名列表，即使旧域名失效也能持续工作。
- **多域名轮换**：一次请求失败立刻切换备选，超时与重试次数随心调节。

## 原图还原，帧帧清晰

- **条带计算**：根据专辑特征与图片序号，精准算出切割条数。
- **条带重排**：按源图位置裁剪、逆序拼接，把碎片还原成完整画面。
- **格式适配**：webp 走重组流程，gif 原样保留，jpg 按需处理，什么都能接。

## 成册优雅，观感统一

- **统一宽度**：所有页面等比缩放到一致宽度，只缩小、不放大，杜绝突兀。
- **零白边**：页面即图片，不留白色占位，翻开就是干净的整页画面。
- **标题命名**：以漫画标题为文件名，清理非法字符，一眼认出是哪一本。

## 一切可配，开箱即用

全部关键参数集中在 `src/config/app-config.json`，无需改一行代码：

- 域名列表（HTML / API / CDN / 域名服务器）
- 应用密钥与版本号
- 请求头与超时重试
- 下载并发上限
- PDF 页面尺寸与最大宽度

## 工程严谨，为长期而生

- **前后端分离**：业务核心独立于界面，逻辑可测试、可复用。
- **多运行时**：Capacitor / Web / Node 共用同一套接口，验证与真机运行行为一致。
- **全量测试**：核心算法均有单测守护，改得放心。
